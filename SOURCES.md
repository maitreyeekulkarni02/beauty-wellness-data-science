# Source register

- **Sephora Skincare Reviews & Sentiment dataset mirror (dataset documentation)**: https://huggingface.co/datasets/haoxianc/natashamessier_sephora-skincare-reviews-and-sentiment — Dataset documentation describes 40,234 customer reviews across 2,012 skincare products; verify the actual files, schema, and license before use.
- **Related Sephora skincare classification project (methodological reference)**: https://github.com/meiw02/skincare-review-classification — Illustrates a workflow using skincare product/review data, cleaning, feature selection, classification, and class-imbalance discussion; not treated as evidence for this project's results.
- **UCI Online Retail dataset**: https://uci-ics-mlr-prod.aws.uci.edu/dataset/352/online%2Bretail — A real transaction dataset, but it concerns giftware rather than beauty products; optional only for practicing retail analytics, not the core analysis.
- **openFDA Cosmetics Adverse Events API**: https://open.fda.gov/apis/cosmetic/event/ — Official US cosmetic adverse-event reporting resource; reports are not a measure of incidence or proof of causation.
- **FDA cosmetic adverse event dashboard announcement**: https://www.fda.gov/news-events/press-announcements/fda-launches-real-time-adverse-event-reporting-dashboard-cosmetic-products — Explains public access to cosmetic adverse-event reports and the dashboard.
- **pandas documentation**: https://pandas.pydata.org/docs/ — Data loading, cleaning, transformation, and tabular analysis.
- **scikit-learn documentation**: https://scikit-learn.org/stable/ — Model pipelines, train/test splitting, preprocessing, and evaluation.
- **Matplotlib documentation**: https://matplotlib.org/stable/ — Static charts and figures.
- **Seaborn documentation**: https://seaborn.pydata.org/ — Statistical visualization.
